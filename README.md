# 现代材料分析与原理 · 学习网站

北京大学「现代材料分析与原理」课程学习网站（GitHub Pages 静态站）。

- **19 篇万字课件讲解稿**，三大模块：光刻工艺 / 传感与生物 / 电学测量仪器
- **522 页逐张图文对照**：PPT 页面图 + 讲解稿
- **19 个交互式 3D 演示**（`3d/` 目录，iframe 懒加载）

## 结构

| 路径 | 内容 |
| --- | --- |
| `index.html` | 主站（单文件：内联 CSS/JS + 图片懒加载） |
| `现代材料分析与原理_学习网站.html` | 旧入口，301 式跳转到 `index.html`，保留旧书签 |
| `assets/pages/` | 522 张课件页面图（jpeg，均有 `loading="lazy"` 与 alt） |
| `3d/` | 交互式 3D 演示（mask_aligner、oscilloscope 等 19 个） |

## 部署

GitHub Pages 从 `main` 分支直接发布，push 即上线。

> 注意：图片总量约 61 MB，全部按需懒加载，首屏只有 HTML 与 20 张封面缩略图；仓库 git 历史里保留过旧版大文件，如嫌克隆慢可择机清理历史（BFG）。
